# Guia-IA-para-profesores-de-FP
Guía  práctica para docentes de FP sobre el uso de la IA en el aula y su práctica docente. 


IA para profesores de Formación Profesional
Guía interactiva de un solo archivo HTML sobre inteligencia artificial para docentes de FP. Va de lo más básico —qué es la IA, cómo funciona un modelo de lenguaje— hasta el uso de la IA para fomentar el pensamiento crítico en el aula, con ejemplos aplicados a distintas familias profesionales.
Creada por V. López (@sanidadedtech).
Ver la guía
Abre `ia-para-profesores-fp.html` directamente en el navegador, o publícala con GitHub Pages para tener una URL propia (ver más abajo).
Contenido
17 secciones agrupadas en cuatro bloques:
Fundamentos — qué es la IA, cómo "piensa" un modelo de lenguaje, el ecosistema de herramientas disponibles.
Aplicación docente — programaciones y UDs con IA, ejemplos por familia profesional, evaluación y feedback, atención a la diversidad, prompts para docentes.
Ética y límites — RGPD y protección de datos del alumnado, marcas de agua de Claude y por qué no valen como prueba de sanción, riesgos y límites de la IA en el aula.
Pensamiento crítico — por qué las humanidades ganan valor en la era de la IA, técnicas concretas para entrenarlo, fichas de actividad listas para usar, autoevaluación y glosario.
Características técnicas
Archivo único, sin dependencias de build ni backend: HTML, CSS y JavaScript vanilla en un solo `.html`.
Índice lateral con scrollspy (se adapta a barra horizontal deslizable en móvil).
Barra de progreso superior con trazado de electrocardiograma (PQRST) que se "dibuja" según se avanza en la lectura.
Pestañas interactivas con ejemplos por familia profesional.
Acordeones para técnicas y fichas de actividad.
Autoevaluación tipo quiz con corrección y explicación inmediatas.
Totalmente responsive, probado desde 320px de ancho.
Sin librerías externas más allá de las tipografías de Google Fonts (Bricolage Grotesque, Inter, JetBrains Mono).
Publicar con GitHub Pages
Sube este repositorio a GitHub.
Ve a Settings → Pages.
En Source, selecciona la rama principal (`main`) y la carpeta raíz (`/`).
Guarda. GitHub publicará la guía en `https://<tu-usuario>.github.io/<nombre-repo>/ia-para-profesores-fp.html`.
Personalización
Los colores, tipografías y el resto de tokens de diseño están centralizados en las variables CSS `:root` al principio del archivo (`--black`, `--red`, `--pulse`, `--white`, `--paper`, etc.), por lo que se pueden ajustar sin tocar el resto del código.
